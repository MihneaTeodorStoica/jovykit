JovyKit

A venv-like command line for project-local JupyterLab environments: readable Compose files, uv-based Python images, simple package overlays, and lifecycle commands that behave like Docker Compose.

Local by default

A project gets compose.yaml, Dockerfile, requirements.txt, work/, and .jupyter/.

02

Reproducible overlays

Project packages live in requirements.txt. The generated Dockerfile installs them with uv on top of the selected Python-tagged image.

03

Comfortable operations

up, down, start, stop, config, and logs follow Docker Compose.

Workflow

From empty folder to working notebook.

Init jovy init --image-level base --python 3.13
Add jovy add pandas plotly scikit-learn
Build jovy build
Run jovy up -d
Why it exists

Docker power without Docker-shaped daily work.

Research projects often start as notebooks, then grow into packages, scripts, and repeatable environments. JovyKit keeps that path grounded in normal files instead of one-off container state.

You still get Docker Compose, GPU reservations with gpus: all, custom volumes, and a generated overlay image. JovyKit keeps the common notebook workflow short.

Image levels

Start small. Scale the stack when the work asks.

minimal

JupyterLab, add-ons, Nitro CLI, uv, and the runtime needed to start fast.

base

Everyday data science, statistics, and classical ML without extra apt tools.

extended

Lighter advanced stats, model inspection, APIs, visualization, spreadsheets, web scraping, and database clients.

full

The huge batteries-included stack for ML, AI, cloud, distributed, apps, graph, geospatial, and research tooling.
