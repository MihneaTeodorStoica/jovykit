# Security

JovyKit uses generated Docker Compose defaults with a local-first security posture.

## Network exposure

- By default, the generated `compose.yaml` maps one exposed service port:
  `127.0.0.1:<host-port>:8888`.
- Jupyter remains loopback-only by default and is not reachable from other hosts.
- If you edit `compose.yaml` to a non-loopback host bind (for example `0.0.0.0`),
  treat it as public network exposure for the full JupyterLab surface.
- For any public exposure, pair this with explicit hardening:
  firewall rules, VPN, reverse-proxy auth, and network allow-lists.

## Authentication

- Jupyter uses `--ServerApp.token=${JUPYTER_TOKEN}` in the container startup
  command.
- A random token is generated by default when creating a project.
- `jovy token show` prints the current local URL and token.
- `jovy token rotate` updates `compose.yaml` with a new generated token.
- `jovy token rotate --token NEW_TOKEN` sets an explicit token.
- If you need a full reset, edit `compose.yaml` directly and restart:
  `jovy down`, `jovy up -d`.
- `jovy open` prints a tokenized URL; do not post-share that URL.

## Persistent state and secrets

- `compose.yaml` is generated source-of-truth and is written to disk in plain text:
  - `JUPYTER_TOKEN`
  - `ports`, `environment`, and build settings
  - GPU and service metadata
- `./.jupyter` is mounted as `/home/jovyan/.jupyter` and persists across rebuilds.
  This folder can contain notebooks, custom kernels, credentials, and extension settings.
- Keep these paths out of published/shared artifacts when they include sensitive state.

## Docker permissions

- `jovy` commands require Docker daemon access.
- The installer note says adding your user to the `docker` group grants root-equivalent
  host access.
- Manage that group membership as a host privilege boundary.
- A process with Docker group access can perform most operations available to root on
  the host via `docker` and `/var/run/docker.sock`.

## Practical checklist

- Keep `compose.yaml` and generated tokens under version control review.
- Do not bind `ports` to a public interface without explicit intent.
- Rotate `JUPYTER_TOKEN` after sharing a containerized environment.
- Review `.jupyter` contents before sharing project directories.
