# Security Policy

## Supported Versions

Security fixes are handled on the default branch. Published container images are
rebuilt through the repository automation.

| Version | Supported |
| ------- | --------- |
| `main`  | Yes       |

## Reporting a Vulnerability

Please report suspected security vulnerabilities privately by email:

Mihnea-Teodor Stoica <ms7322@columbia.edu>

Please include:

- A description of the issue.
- Steps to reproduce or verify it.
- The affected files, dependencies, images, or workflows.
- Any known impact or exploitability details.

Please do not open a public issue for a suspected vulnerability until it has
been reviewed.

## Response Expectations

You can expect an initial response within 7 days. Valid reports will be
prioritized based on severity, exploitability, and affected users.
